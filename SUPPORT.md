# Support

For product questions, reproducible defects, and improvement proposals, use GitHub Issues when appropriate.

Before reporting a defect, include the page/workflow, reproduction steps using non-sensitive data, expected versus observed behavior, browser/device, approximate time, and sanitized screenshots/logs if available.

Do not include passwords, API keys, authentication tokens, private user records, or payment information. Report security vulnerabilities using SECURITY.md, not a public issue.

This prototype uses AppDeploy-hosted authentication, persistence, and runtime integrations. A failure may depend on the hosted environment. Report the app URL and approximate time; do not attempt to access another user's data.
